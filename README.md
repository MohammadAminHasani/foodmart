# Foodmart

A responsive food e-commerce website built from scratch using HTML5 and CSS3.

## Preview

![Foodmart Preview](/assets/images/Preview.png)

## Features

* Responsive layout for desktop, tablet, and mobile
* E-commerce-style product cards
* Hero section
* Product sections
* Category/feature sections
* Newsletter subscription section
* Responsive navigation
* Custom CSS styling
* Flexible layouts using Flexbox

## Tech Stack

* HTML5
* CSS3
* Flexbox
* CSS Media Queries

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/MohammadForge/foodmart.git
cd foodmart
```

### 2. Run the project

Open `index.html` directly in your browser, or use **Live Server** in VS Code for the best development experience.

## Responsive Design

Foodmart uses flexible layouts and CSS media queries to adapt the interface to different screen sizes, including desktop, tablet, and mobile devices.

## Development Notes

The project was intentionally built without a CSS framework to strengthen my understanding of:

* Semantic HTML
* CSS layout systems
* Flexbox
* Responsive design
* Media queries
* Component-style layouts
* Frontend debugging
