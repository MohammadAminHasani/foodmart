# Foodmart

A responsive food e-commerce web application built with **HTML, CSS, and vanilla JavaScript**, focused on product discovery, interactive shopping features, and dynamic user interfaces.

## Overview

**Foodmart** is a browser-based e-commerce application that provides users with a modern interface for browsing and interacting with food products.

The application includes **product search and filtering, wishlist functionality, and an interactive shopping cart**. JavaScript is used to handle user interactions and dynamically update the interface without requiring page reloads.

The main goal of the project is to apply practical front-end development concepts while building a realistic e-commerce experience.

## Project Highlights

### Product Search and Filtering

Users can search through available products and filter products by category. The interface updates dynamically based on the selected criteria.

### Shopping Cart

The application provides an interactive shopping cart where users can add products and manage their current selections.

The cart interface dynamically reflects the user's current selections and item count.

### Wishlist

Users can mark products as wishlist items directly from the product interface.

### Dynamic Interface

JavaScript handles interactions between the user and the application, allowing product-related actions to update the interface without requiring full page reloads.

### Responsive Design

The interface is designed to adapt to different screen sizes, providing a consistent experience across desktop and smaller devices.

## Development Focus

Foodmart was built to demonstrate **practical front-end development through a realistic e-commerce application** rather than a static website.

The project focuses on connecting **HTML structure, CSS presentation, and JavaScript application logic** into a functional user experience.
